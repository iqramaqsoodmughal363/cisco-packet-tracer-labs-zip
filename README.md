## 📋 Overview

This repository contains a comprehensive collection of **Cisco Packet Tracer (`.pkt`) files**. These files are designed to help students and networking enthusiasts practice and master core networking concepts. 

From basic topologies to complex multi-area OSPF routing and VLAN configurations, this collection covers a wide range of practical scenarios.

---

## ✨ Key Features & Contents

This repository includes fully functional Packet Tracer labs, categorized into:

* **🧪 Basic Labs:** Fundamental configurations like DHCP, FTP, CDP/LLDP, and EtherChannel.
* **💻 Practicals:** Step-by-step practicals covering topologies (Bus, Star), IP routing, SSH, and Duplex modes.
* **🚀 Full Projects:** Complete network designs including Small Office setups, Branch Office WANs, and a Campus WAN Lab.
* **🔐 VLAN & ACLs:** Dedicated labs for VLAN configurations, VLAN Trunking, and Access Control Lists (ACLs).
* **🌐 Routing Protocols:** Labs focusing on RSTP, OSPF (Single & Multi-Area), and Static Routing.

## 🚀 How to Use

### Prerequisites
* **Cisco Packet Tracer** (Version 8.0 or higher recommended).
* A Cisco NetAcad account (required to log into Packet Tracer).

### Steps

1. **Clone or Download**
   ```bash
   git clone https://github.com/iqramaaqsoodmughal363/cisco-packet-tracer-labs.git
   ```
   *(Or simply download the provided `.zip` file and extract it).*

2. **Open a File**
   * Launch Cisco Packet Tracer.
   * Go to **File → Open**.
   * Select any `.pkt` file from the downloaded folder.

3. **Run and Test**
   * Use the **Realtime** tab to test pings, routing tables, and connectivity.
   * Click on devices and go to the **CLI** tab to view or modify configurations.
